# 《云朵果冻铺》MVP v5

这是仍在研讨的手感 MVP，不是已经定稿的正式工程。玩法方案原文在 [`玩法方案.md`](玩法方案.md)。方案写于 2026-11-25，文首状态是「只做评估和方案」。后来的确认写在 [`docs/沟通与决策记录.md`](../docs/沟通与决策记录.md)：方案已通过，并要求做手感 MVP；当前验收是 v5 已部署在 https://guodong.sakuralost.com/ ，等试玩确认。没说「通过」之前，不进入正式开发。

## 目录里有什么

附件解压后的文件都在这里：

| 路径 | 内容 |
| --- | --- |
| `index.html` | 浏览器里的 MVP 页面，用 Canvas 跑下面的脚本 |
| `css/site.css` | 页面样式 |
| `wechat-minigame/js/` | 规则、关卡、音效、对局和界面脚本 |
| `wechat-minigame/images/` | 果冻、匙、轨道等图片 |
| `玩法方案.md` | 路线评估与玩法方案全文 |

这包 MVP 没有单独的 `game.js`、`game.json` 或 `project.config.json`。`wechat-minigame/js` 是给上面的网页引用的脚本目录，还不是一个已经用微信开发者工具导入的小游戏工程。

## 本地预览

用浏览器打开本目录的 `index.html`。若图片加载被浏览器拦住，在本目录执行：

```bash
python3 -m http.server
```

再打开终端里给出的地址。已部署的试玩是 https://guodong.sakuralost.com/ 。

## 已经定下的玩法

记录里已经写明、并且要求做进 MVP 的几点：

- 保留从下往上发射。这是对标 Magical Drop 的核心手感，不改成从上往下落。
- 抓取、蓄力、发射要有更容易看懂的动效，动效不能被发射台挡住。
- 底部是操作区，要同时有文字引导和操作区的视觉引导。
- 底部提示环不要乱跳。只在前 2 关，对建议操作的那一列跳两下。

技术方向在方案和记录里都写了：竖屏、2D 离散网格、连通消除；个人主体、只靠广告、先单机；主程序方向是微信 `game.js` + Canvas。本目录目前交付的是上述网页 MVP。
