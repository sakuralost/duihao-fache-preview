# 对号发车 · 微信小游戏

用微信开发者工具打开的是 **小游戏** 工程，不是小程序。网页版仍在 `../v2/`，本目录是独立的微信版，互不影响。

- 账号 AppID：`wx3fad237336dba3ba`
- 名称：对号发车
- 主体：个人，只靠广告、不开虚拟支付

## 用微信开发者工具打开

1. 安装并登录 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择 **小游戏** → **导入项目**（不要选「小程序」）。
3. 目录选本文件夹 `wechat-minigame`。
4. AppID 填 `wx3fad237336dba3ba`（`project.config.json` 里已写好）。
5. 用模拟器或预览到手机即可开局。开发者工具控制台里可以用 `DH.startLevel(n)` 跳到第 n+1 关（例如 `DH.startLevel(4)` 是第 5 关）。

工程入口是根目录的 `game.js`，配置为 `game.json` + `project.config.json`（`compileType` 为 `game`）。

## 数据统计（关卡进度）

游戏里已经埋好上报，只通过微信的 `wx.reportEvent` 发到公众平台的「自定义分析」，**不会把玩家身份或进度存到我们自己的服务器**，因此仍符合单机承诺。

会上报这些事件（数字 `level` 为 1–20）：

| 事件 ID | 何时 | 参数 |
| --- | --- | --- |
| `game_open` | 每次冷启动 | 无 |
| `level_start` | 进入或重开一关 | `level`，`action`（enter / retry） |
| `level_win` | 过关 | `level`，`stars`，`undos`，`revived`（0/1） |
| `level_fail` | 失败 | `level`，`reason`（full / stuck） |
| `share_unlock` | 分享解锁车位成功 | `level`，`extra`（本局已解锁数） |
| `ad_revive` | 看广告复活成功 | `level` |
| `undo` | 撤销 | `level`，`via`（free / ad） |

上线后这样看：

1. 打开人数、留存：公众平台 → **数据分析 / 数据助手**（平台自带，不必再埋点）。
2. 各关尝试、过关、失败，以及大概最多玩到哪一关：先在公众平台把上面这些事件和参数建好（**统计 / 自定义分析**），游戏上报后即可按 `level` 做分布或漏斗。数据通常会有数小时延迟。
3. 本地预览和未登录的开发环境不会上报。

事件需要在后台创建一次后，正式数据才会进报表。上线前我可以帮你在公众平台把事件建好。

## 仍是占位、需要你补的

**激励广告还没有广告位 ID。** 流量主开通后，把广告位 ID 填进 `js/config.js` 里的 `AD_UNIT_ID` 即可换成真广告（`wx.createRewardedVideoAd`）。现在留空时会弹出「观看（广告占位 · 未开通流量主）」倒计时，看完给予同样的复活或撤销奖励，方便先把流程跑通。

**分享**已接 `wx.shareAppMessage`。微信不返回是否分享成功，回到游戏时用 `wx.onShow` 判断：离开超过约 0.4 秒视为已分享并解锁车位；马上取消则不解锁。系统菜单分享不会自动加车位，只有点锁着的车位或失败卡上的分享才会。

## 本地网页预览（可选，不能代替开发者工具）

本机调试可以用项目内的预览页（不要把 `tools/` 上传到微信）：

```bash
cd wechat-minigame
node tools/bundle-preview.js
PORT=33605 node tools/preview-server.js
# 浏览器打开 http://127.0.0.1:33605/
```

本地预览里分享会走 2 秒占位，广告同样走倒计时占位。
